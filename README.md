# Proyecto: reto_soft

**Estructura del Proyecto y Propósito**

* **`/public`**: Contiene todo el código del Frontend
  * `/assets`: Archivos estáticos como imágenes.
  * `/css`: Hojas de estilo.
  * `/js`: Lógica del cliente, como `main.js`, donde se interactúa con el DOM y se hacen peticiones al backend.
  * `/pages`: Vistas HTML secundarias.
  * `index.html`: La página principal de la aplicación.
* **`/src`**: Contiene el código del Backend.
  * `main.js`: El archivo principal del servidor `public` y define las rutas de la API.
* **`.env`**: Archivo de configuración para variables de entorno. **No debe subirse a Git.**
* **`.gitignore`**: Lista de archivos y carpetas que Git debe ignorar.
